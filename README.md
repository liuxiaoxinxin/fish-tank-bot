# 鱼缸壁面清洁机器人 — 结构设计

吸附在鱼缸玻璃壁面上、靠封闭死容积负压固定的爬壁清洁机器人。
整机接近中性浮力，步进式运动，无真空泵、无气动管路。

## 文档

| 文档 | 内容 |
|---|---|
| [suction.html](suction.html) | **吸附单元** — 空心杯电机 + 丝杆驱动膜片形变产生负压。剖面图、双状态对比、面积解耦、吸力核算、设计要点 |
| [motion.html](motion.html) | **运动单元** — 三足 3-RPR 并联平台步态。剥离力矩分析、逐帧运动分解、刷辊作业载荷、方案对比、性能估算 |
| [work.html](work.html) | **作业机构** — 主机 / 可换作业头分层。清洁元件选型、刷辊 + 刮条组合、效率分析、磁耦合免工具快换、扩展接口 |

用浏览器直接打开即可，无需服务器。

## 基准配置

```
吸盘开口      ∅25 mm      吸力 12.27 N @ −25 kPa
驱动膜片      ∅20 mm      电机只需 7.85 N
丝杆导程      0.3 mm      电机扭矩约 1.25 mN·m
有效重量      0.3–0.5 N   近中性浮力，略重于水
```
