# 鱼缸壁面清洁机器人 — 结构设计

吸附在鱼缸玻璃壁面上、靠封闭死容积负压固定的爬壁清洁机器人。
整机接近中性浮力，步进式运动，无真空泵、无气动管路。

## 基准配置

```
吸盘开口      ∅25 mm      吸力 12.27 N @ −25 kPa
驱动膜片      ∅20 mm      电机只需 7.85 N
丝杆导程      0.3 mm      电机扭矩约 1.25 mN·m
有效重量      0.3–0.5 N   近中性浮力，略重于水
运动方案      三足 3-RPR   3 × ∅25 吸盘，R_t = 100 mm，铰点圆错开 60°，步距 12–23 mm
整机质量      1097 g      其中配重约 253 g，可调（换面件称重后配重降到约 200–210 g）
主体总厚      64 mm       O 圈 ∅2.0，槽 2.6 × 1.6 mm
穿舱点        0 个         充电走感应坞站，调试走无线，恢复入口是磁控开关
坞站间隙      13.0 mm      玻璃占 5 mm，其中线圈间隙 8 mm
坞站功率      5 W → 2.2 W 端到端效率 45%，每次停留约 5 min
对接精度      ±5 mm        捕获范围 ±25 mm，判据连续 200 次 ≥ 99%
作业频次      每天 3 次     每次 2.1 min（一面墙）→ 0.4 Wh/天
过棱换面      必须支持      含 90° 直角棱；每条腿加面外俯仰轴 + 被动弹簧膝，电机 10 个
换面代价      ≈ 2–3 min    每次约 0.1 Wh —— 与擦完一整面墙同量级，要排程（量级估算）
驻留方式      回坞站待机   不作业就回坞，吸盘松开，中途低电也回坞补
待机目标      < 1 mW       整板深度睡眠 < 50 µA，唤醒周期 30 min（设计目标，非硬约束）
主控          机器人 ESP32-S3（无 PSRAM） / 坞站 ESP32-C6 + RV1106
通信          BLE 穿玻璃 + 坞站 MQTT/TLS 上云 + App 远程
```


## 仓库文件

```
index.html         文档总目录（浏览入口）
AGENTS.md          文档设计规范（唯一真实来源，改动前先读）
CLAUDE.md          指向 AGENTS.md
assets/notion.css  全部样式
assets/toc.js      左侧目录导航
```

九篇文档与 `assets/` 是共享关系，不要单独把某一篇拷走。`gimbal/` 子目录里的文档用 `../assets/` 引同一套样式，整个子目录也不能单独拷走。

## 改文档

样式只改 `assets/notion.css`，不要往 HTML 里写 `<style>`。
新增章节后要手工同步左侧目录 —— 规则和自检脚本见 [AGENTS.md](AGENTS.md) 第 2.3 节。

改 [model.html](model.html) 还有两条：尺寸只写在 `CFG` 一个对象里，
零件一个 `build*()` 函数画一个；three.js 的版本钉死在 importmap 里，
代码必须内联（`file://` 下本地 ES module 会被 CORS 拦死）。见
[AGENTS.md](AGENTS.md) 第 6 节。
